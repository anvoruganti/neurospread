# NeuroSpread site

Dark clinical Next.js 14 app that plays the computed seizure movies from `public/`.

```bash
cd web
npm install
npm test
npm run dev
```

Open http://localhost:3000. Live Q&A needs `OPENAI_API_KEY` in the environment. Without it, the walkthrough still shows and `/api/ask` returns 503.

This is a public-data proof of concept. It is not diagnostic.
